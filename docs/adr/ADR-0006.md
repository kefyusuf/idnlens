# ADR-0006 — Chrome MV3 committed-navigation badge and popup

- **Status:** Proposed
- **Date:** 2026-10-15
- **Owner:** Maintainer (pending review)
- **Scope:** M1 only

## Context

webNavigation observes lifecycle events but does not intercept network requests. Intrusive overlays, content scripts or redirects would require additional capabilities.

## Decision

Observe Chrome webNavigation.onCommitted for top-frame HTTP(S) navigation (frameId 0); run M0 analysis and display a small action badge with an accessible popup for REVIEW or LOOKALIKE. Clear stale tab state on navigation. No page overlays, content scripts, mutation, remote APIs or automatic blocking.

## Alternatives considered

Incorrect assumption of blocking with onBeforeNavigate; page overlay; declarativeNetRequest in v0.

## Consequences

Minimal UI and permissions but warnings may appear after page loading.

## Evidence required for acceptance

Browser-level checks for redirects, reloads, tab switches, worker suspension, rapid navigations, iframe exclusion and stale-state prevention.

## Decision gate

This ADR remains proposed. Acceptance requires the evidence and scope review described in the roadmap. Do not treat this document as implemented behavior.
