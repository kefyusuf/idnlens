# ADR-0004 — Explainable outcomes instead of safety verdicts

- **Status:** Proposed
- **Date:** 2026-10-15
- **Owner:** Maintainer (pending review)
- **Scope:** M0/M1

## Context

Visual confusability is a signal, not proof of maliciousness. A missing signal must not be interpreted as proof of safety. Risk scores would imply unjustified calibration.

## Decision

Return NO_INDICATOR, REVIEW, LOOKALIKE or UNSUPPORTED with bounded evidence, relevant Unicode code points, protected-domain match when applicable, and dataset versions. Unsupported input takes precedence; otherwise LOOKALIKE outranks REVIEW, which outranks NO_INDICATOR. Never produce safe, trusted, malicious, verified, or confidence percentages.

## Alternatives considered

Binary safe/unsafe labels; numerical security scores; alerting on all non-ASCII names.

## Consequences

Clearer, honest and testable output; less visually dramatic than a binary safety shield.

## Evidence required for acceptance

JSON Schema checks, priority tests, legitimate IDN negative cases, deterministic evidence ordering, and prohibited-claim review.

## Decision gate

This ADR remains proposed. Acceptance requires the evidence and scope review described in the roadmap. Do not treat this document as implemented behavior.
