# ADR-0007 — Local processing and minimum permissions

- **Status:** Proposed
- **Date:** 2026-10-15
- **Owner:** Maintainer (pending review)
- **Scope:** M0/M1

## Context

Browsing destinations are potentially sensitive. An extension should not become an additional tracking surface or require broad permissions for speculative future features.

## Decision

M0 uses no storage/network/browser APIs. M1 handles only top-frame hostnames and minimal per-tab evidence, optionally in chrome.storage.session. Never transmit visited hostnames or retain paths, queries, fragments, credentials or browsing-history lists. Evaluate webNavigation, storage and action permissions first; add any host permission only with proven necessity. Render hostname as text, never HTML.

## Alternatives considered

Remote telemetry/reputation; permanent local history; all_urls/tabs/content-script permissions by default.

## Consequences

Reduced collection and easier audit at the cost of remote diagnostics and with careful session lifecycle requirements.

## Evidence required for acceptance

Manifest, network and bundled-code audits; session storage inspection; Chrome Web Store privacy and permission checks.

## Decision gate

This ADR remains proposed. Acceptance requires the evidence and scope review described in the roadmap. Do not treat this document as implemented behavior.
