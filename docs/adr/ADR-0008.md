# ADR-0008 — Defer click interception and automatic blocking

- **Status:** Proposed
- **Date:** 2026-10-15
- **Owner:** Maintainer (pending review)
- **Scope:** M1

## Context

False positives can deny access to legitimate multilingual sites. Request control requires separate API, permission, race and reversal analyses; committed navigation cannot block the initial request.

## Decision

Do not block, redirect, rewrite navigation history or intercept clicks during M0/M1. Promise to detect and explain possible Unicode lookalikes, not to prevent phishing. Reconsider only through a new ADR, measured false positives, API feasibility tests, override/rollback design and explicit review.

## Alternatives considered

Block all mixed-script domains; redirects to interstitial; immediate DNR rules.

## Consequences

Truthful smaller MVP, at the cost of no prevention guarantee before page load or credential entry.

## Evidence required for acceptance

Inspect source, manifest, browser tests, README and store copy to ensure no blocking claims or request-modification code.

## Decision gate

This ADR remains proposed. Acceptance requires the evidence and scope review described in the roadmap. Do not treat this document as implemented behavior.
