# ADR-0005 — Maintain a finite protected-domain catalog

- **Status:** Proposed
- **Date:** 2026-10-15
- **Owner:** Maintainer (pending review)
- **Scope:** M0/M1

## Context

Many legitimate internationalized domains can be visually confusable. Unbounded internet-wide comparison is neither practical nor explainable.

## Decision

Use a small exact list of protected registrable domains injected into M0 and, after review, bundled in M1. Compare normalized registrable identities only for the same public suffix. The identical canonical registrable domain is not an impostor. No arbitrary substring, ASCII edit-distance heuristic, automated brand crawling or remote feed.

## Alternatives considered

Download popular-domain rankings; user-customized thousands of brands; omit protected targets and only detect scripts.

## Consequences

Bounded deterministic scope and tractable false-positive review; known limitation for cross-TLD and uncatalogued names.

## Evidence required for acceptance

Exact/same-suffix/whole-script examples, cross-TLD negative tests, compound suffixes and a reviewed catalog manifest.

## Decision gate

This ADR remains proposed. Acceptance requires the evidence and scope review described in the roadmap. Do not treat this document as implemented behavior.
